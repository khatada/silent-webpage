# ピクセルアートの補正と採用

ユーザー指定により、今後のピクセルアートは補正後にLLMが画像を確認し、採否を記録してから採用する。自動変換の成功だけでは採用しない。手続き描画も対象とし、代表画像を出力して確認する。

## 補正プログラム

```sh
npm run art:correct -- --input original.png --output corrected.png --cell-size 2.25 --offset-x 0 --offset-y 0 --scale 2
```

- `cell-size`: 元画像の1ドットの幅・高さ。小数も指定できる。
- `offset-x/y`: 元の格子原点。0以上、cell-size未満。
- `scale`: 補正後1ドットの整数倍率。1はネイティブ画像。
- 元画像は保持し、出力先の上書きは禁止する。
- 各セルの最多RGBA色を採用。同数の場合はセル中心に近い色を使う。透明度は保持する。端の不完全なセルは切り落とす。
- 出力PNGと `.png.json` の設定・入出力SHA256をセットで保存する。

格子幅は目視と作成時の設定から決める。自動推定や局所的な歪みの自動修復は行わない。ずれた部位が残る、細部が失われる場合は採用せず、格子設定または原画を修正して再実行する。元画像が既に1px格子ならcell-size 1で補正し、変化がないことも確認する。

## LLMによる採否

1. 元画像と補正画像を出力する。アニメーションは代表姿勢とPC・縦長画面を含める。
2. 補正画像をLLMの画像閲覧機能で実際に開く。
3. ドットの整列、輪郭、窓・猫などの細部、配色、構図の破損を確認する。
4. 対象画像・ハッシュ・補正設定・採用/不採用・判断理由を記録する。ファイル名や変換ログのみで採用しない。
5. 不採用なら修正と補正を繰り返す。採用記録を作る前に公開用素材へ反映しない。

ユーザーへの承認依頼は不要。これはエージェント自身が行う確認工程である。
